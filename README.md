# 『40歳、宇宙出張。』公式サイト v0.1

スペースオペラ × 恋愛小説。著者：綺羅星の猫。

[小説家になろうで読む](https://ncode.syosetu.com/n0686mv/)

このリポジトリは、承認された読者向けの完成サイトだけを保存します。
小説本文、執筆エンジン、設定資料、制作プロンプト、未公開の人物情報や作者用画像は含みません。
エピソード案内は第40話までの公開済み目次に基づきます。
人物紹介は初登場時の情報を中心に掲載し、未公開の詳細は公開しません。
初登場時の紹介は「第21〜30話を読んだ方向け」、その後に明かされた情報は「第31〜40話を読んだ方向け」の折りたたみ内に分けます。
第37話で伝えられたリセの呼び名は、所属・出身の開示とは別に扱います。
直人・美緒・真琴の仕事紹介は第33〜40話の公開された担当範囲に限ります。
名乗っていない人物には名前・所属を補いません。本文未記載の人物画の細部は紹介用の解釈です。
エピソードは第0〜10話、以降は第11〜20話、第21〜30話のように10話単位で区切ります。
未公開の枠や題名は掲載せず、各話のリンクは公開された本文を直接開きます。
TOPのロゴと人物画像は別の領域へ配置し、画面幅が狭い場合は縦に並べます。
WORLDは第40話までに登場した地球と宇宙ステーションを紹介します。
地球／ステーションの切り替え、食堂・仕事場・居室・窓辺の案内、食事袋の固定／浮遊演出があります。
食堂の受取端末では紹介用の番号を選び、夕飯袋を受け取る小さな演出を試せます。
搬入側の確認通路、器を評価する作業台、共用の説明室を追加し、登場話へリンクします。
「袋が、ご馳走になる！」は食品袋・地上の盛り付け例・微小重力の固定トレイの3段階を切り替える、読了者向けの紹介用イラストです。
蓋付きの器とトレイ、身体を固定して評価する場面を根拠にし、地上の皿をそのまま宇宙へ持ち込む表現にはしません。
料理の造形と器は紹介用で、商品写真・完成品・公式設備の再現ではありません。
食卓比較はリアル寄りの料理イラスト3枚で表示します。「地上の食卓」は、お皿に盛り付けた例を意味します。
同じ献立の見せ方を比較するための絵で、具体的な副菜・包装・器の細部を本文の設定として確定しません。
WORLDの紹介用演出では実際の予約・通信・音声再生・計測・保存は行いません。キーボードで操作できます。アクセス解析は別のスクリプトと下記の公開説明で扱います。
窓の外は雲と大気の縁を描いた、リアル寄りのアニメ背景です。背景画像と操作パネルは独立したレイヤーで表示します。
図・配置・動きは紹介用のイメージで、公式の施設構造図や物理シミュレーションではありません。
未公開の土地・人物・設定は、隠しデータとしても配信しません。
アニメーションは停止でき、OSの動きを減らす設定にも対応します。JavaScriptを無効にしても生活メモを読めます。

## 構成

PV第1弾は30秒の導入編として残します。第2弾は公開第0〜40話に限定した60秒・1080p・60fpsのモーションPVです。
第2弾は読者向けの案内付き折りたたみ内に置き、自動再生・音声台詞・二重字幕は加えません。
静止画のカメラ移動・ディゾルブとBGMによる作品紹介で、フルアニメーションや本文の正史を確定する映像ではありません。
第2弾の音楽は「Starlight Room」。クレジット「Made with ElevenMusic」は映像内と再生欄の両方に表示します。
音楽の利用条件は [ElevenMusic Terms of Service](https://elevenmusic.io/terms-of-use) を参照してください。音楽単体の配信や利用者への再利用許諾を示すものではありません。
制作スクリプト・プロンプト・生成元パスは保存せず、確認済みの完成映像とポスターだけを配信用に許可します。

- `docs/`：配信用のHTML・CSS・WORLD操作用JavaScript・独立したアクセス解析スクリプト・画像・30秒ティザーと60秒第2弾PV（BGMのみ・焼き込み字幕）。
- `public-manifest.json`：公開ファイルのSHA256一覧。
- `verify.mjs`：ファイル許可リスト、ハッシュ、リンク、公開メタデータを検査するローカルツール。
- `analytics.test.mjs`：外部通信なしで計測・除外・停止・送信情報削減を検証する回帰テスト。`node verify.mjs` からも実行します。

依存パッケージの追加なしで `node verify.mjs` を実行できます。
静的ファイルは完成済みなのでビルド処理は不要です。

## アクセス解析

Umami Cloudの作品専用Website IDを設定しています。公開用のIDであり、APIキーやログイン情報ではありません。
計測は配信後から始まり、過去のアクセスは復元できません。ダッシュボードの人数は概数で、アクセスが計測されない場合もあります。
実装・検査の完了と、本番配信・Umami管理画面での受信確認は別の段階です。

- 本番ホストと作品のトップページのパスだけで起動し、他作品やローカル確認は対象にしません。
- 手動ページビューは1ページ表示で1回。スクロールやハッシュ移動では増やしません。
- Xの参照元または `utm_source=x` / `utm_source=twitter` を判別できた場合だけ、参照元を固定の `https://x.com/` に置き換えます。それ以外は不明として扱います。参照元なしを「直接訪問の証明」とはしません。
- `narou_click`：この作品のなろうリンク操作。置き場所と、各話リンクでは公開話番号だけを集計します。読了数ではありません。
- `pv_start`：実際に再生が始まった動画。PV01/PV02それぞれ1ページ表示で1回です。再生完了数ではありません。
- 自動計測・操作録画・性能測定・識別IDの送信を無効にし、URLの余分なパラメーターやアンカー、参照元全文、入力内容は送信しません。通信時のIP・ブラウザー情報はサービス側で処理されます。
- DNT/GPC、広告ブロックなどにより計測されないアクセスがあります。通常の閲覧やリンク・動画操作を妨げません。
- ページ末尾「アクセス解析とプライバシー」で計測停止できます。停止設定のみを作品専用の端末保存キーで保存し、同一ホストの他作品用キーは変更しません。送信済みの情報は取り消しません。

作者の確認用URL： [このブラウザーを計測から除外する](https://kiraboshi-neko.github.io/40sai-space-trip-site/?analytics=exclude)。
公開後に、確認に使う各ブラウザーで一度開いてください。停止はそのブラウザー・保存領域だけに適用されます。
`?analytics=off` はそのアクセスだけを除外します。再開はページ末尾のボタンで行えます。
X用のリンク例： [作品サイト](https://kiraboshi-neko.github.io/40sai-space-trip-site/?utm_source=x&utm_medium=social)。

管理画面は [Umami Cloud](https://cloud.umami.is/) の作品専用サイトから確認します。公開の人数カウンターや管理画面共有は追加していません。
利用条件・データ処理は [Umamiのプライバシーポリシー](https://umami.is/privacy) と登録したプランを確認してください。有料契約やアップグレード操作はこのリポジトリから行いません。
